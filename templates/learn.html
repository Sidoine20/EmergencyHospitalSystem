Data Structures & Algorithms Mathematical Foundations

Formal asymptotic analysis ($\mathcal{O}, \Omega, \Theta$), recurrence relations, and invariant proofs mapped directly to clinical hospital operations.

1. Dynamic Array (PatientList)

Contiguous memory allocation with arithmetic address computation: $\text{Address}(A[i]) = \text{Base} + i \times \text{Size}$.

PatientList (Dynamic Python List wrapper)
  • Random Access: $\Theta(1)$ constant time
  • Amortized Append: $\mathcal{O}(1)$ (occasional geometric resize)
  • Prepend / Delete Head: $\Theta(n)$ due to physical element shifting
  • Hospital Role: Master Patient Database Lookup
2. Singly Linked List

Dispersed heap memory nodes linked via explicit pointers: $\text{Node} = (\text{data}, \text{next})$.

Head → Node(104) → Node(101) → None
  • Prepend (Head Insert): Strictly $\Theta(1)$ pointer update
  • Delete Head: $\Theta(1)$ (head = head.next)
  • k-th Element Access: $\Theta(k) \le \mathcal{O}(n)$ sequential hops
  • Hospital Role: Urgent zero-shift triage prepending
3. FIFO Queue

Dual-pointer singly linked chain maintaining front and rear references.

Dequeue(Front) ← [101] ← [102] ← [103] ← Enqueue(Rear)
  • Enqueue at Rear: $\Theta(1)$ pointer assignment
  • Dequeue at Front: $\Theta(1)$ pointer advance
  • Peek Front: $\Theta(1)$ constant time
  • Hospital Role: Outpatient routine consultation line
4. LIFO Stack

Single pointer singly linked chain maintaining a top reference for state history.

TOP → Snapshot(t=2) → Snapshot(t=1) → None
  • Push State Snapshot: $\Theta(1)$
  • Pop (Rollback Action): $\Theta(1)$
  • Auxiliary Memory: $\Theta(n)$ for $n$ historical steps
  • Hospital Role: Clinical audit trail & prescription undo
5. Complete Binary Max-Heap

Complete binary tree of height $h = \lfloor \log_2 n \rfloor$ stored in 1D array.

Parent: ⌊(i-1)/2⌋ | Left: 2i+1 | Right: 2i+2
  • Insert / Sift-Up: $\mathcal{O}(h) = \mathcal{O}(\log_2 n)$
  • Extract-Max / Sift-Down: $\mathcal{O}(h) = \mathcal{O}(\log_2 n)$
  • Peek Max: $\Theta(1)$ index 0 read
  • Hospital Role: Emergency trauma prioritization
6. Asymptotic Search & Sort

Divide-and-conquer recurrences with tight asymptotic bounds.

Binary Search: Ο(log n) | MergeSort: Θ(n log n)
  • Binary Search: $C_{\max}(n) = \lfloor \log_2 n \rfloor + 1$
  • Merge Sort: $T(n) = 2T(n/2) + \Theta(n) \implies \Theta(n \log_2 n)$
  • Quick Sort: In-place average $\Theta(n \log_2 n)$
  • Hospital Role: Multi-tier clinical analytics & reporting
